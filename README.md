# 布布的快乐花园

原创卡通悬疑网页解谜游戏。玩家以公司前插画师的身份，从匿名来信开始调查，在儿童品牌的可爱官网里逐步发现失踪与非法医疗交易的真相。故事含成熟悬疑主题，无血腥画面，无突然惊吓。所有角色、公司与事件均为虚构。

## 本地运行

需要 Node.js 20 或更新版本，无需安装依赖。

```powershell
git clone https://github.com/Listening-star/Happy-Garden.git
cd Happy-Garden
npm start
```

打开 http://127.0.0.1:4317。也可以将 `dist/` 部署到任意静态网站服务器。由于使用浏览器 ES Modules，请通过 HTTP 服务打开，勿直接双击 HTML。

## 包含内容

- 原创 SVG 绘本风格插画，桌面与移动布局。
- 初次打开时显示三页可跳过序章，交代林见夏的身份、匿名求助和最初目标；页脚可随时重读，不重置存档。
- 布布会眨眼、摆耳朵、呼吸、挥手并跟随视线；点击头部或互动按钮可以摸头、打招呼。动作、注视与回应随存档章节逐步变得诡异，完整结局后恢复温柔。支持减少动态效果。
- 序章及六段调查，生日密码、天气顺序、员工登录、事件时间线、封存索引、证据推理与病房定位。
- 十二份证据、可翻阅日记、调查手帐、个人笔记、手帐导出。
- 会员卡背面采用儿童铅笔手写图片，并提供可展开的文字辨认；未剪辑母带附有可检查三个细节的原创旧档案照片。
- 本地自动存档、主动展开的分级提示、可折叠的手帐备注、可选轻柔音乐、减少动态效果支持。已有存档保持已解锁章节；尚未结局的玩家可以继续调查新的病房定位。
- 三个结局，结局后可以重新选择而不重玩所有谜题。
- 全部交互均为浏览器本地模拟，不会发送真实信息或收集个人信息。

## 校验

```powershell
npm run check
npm test
```

`dist/engine.js` 管理解锁逻辑和存档，`dist/story.js` 保存故事内容，`dist/app.js` 管理界面交互，`dist/style.css` 管理画面与响应式布局。

`dist/bubu.js` 与 `dist/bubu.css` 管理兔子的阶段动画和互动；`dist/prologue.js`、`dist/artifacts.css` 管理序章与纸质线索。生成素材和完整提示词见 [ART_DIRECTION.md](ART_DIRECTION.md)。
